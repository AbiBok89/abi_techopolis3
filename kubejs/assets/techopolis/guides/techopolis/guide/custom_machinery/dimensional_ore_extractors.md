# Dimensional Ore Extractors

Duplicates Dimensional Ores. Each ore requires its own Dimensional Ore Extractor.

<Recipe id="techopolis:dimensional_ore_extractor" />

## Dimensional Ore Extractor Mk2

The **Dimensional Ore Extractor Mk2** allows up to **3 Dimensional Ores** to be duplicated. It uses the same structure as the original Dimensional Ore Extractor.
